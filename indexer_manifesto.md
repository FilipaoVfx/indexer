# INDEXER MANIFESTO

Indexer is a technical knowledge operating system.

## Vision

Transform fragmented technical knowledge into executable systems.

## Problem

Developers have access to information but struggle to connect tools, repos, workflows and implementation paths.

Current flow:

Goal → Search → Read → Save → Forget

Desired flow:

Goal → Route → Architecture → Execution

## What Indexer Is

- Knowledge engine
- Route engine
- Architecture planner
- Workflow discovery system

## Core Principles

1. Capabilities before repositories.
2. Routes before results.
3. Context before keywords.
4. Relationships before records.
5. Execution before exploration.

## Goal Mode

Users describe an objective.

Indexer identifies:

- stages
- capabilities
- tools
- alternatives
- dependencies

Then builds an implementation route.

## Knowledge Sources

- GitHub repositories
- READMEs
- bookmarks
- technical articles
- documentation
- videos

## GitHub Vision

Repositories become structured capabilities.

Indexer extracts:

- technologies
- inputs
- outputs
- deployment modes
- integrations
- complexity

## Long-Term Evolution

Search Engine
↓
Knowledge Engine
↓
Route Engine
↓
Architecture Engine

## Ultimate Mission

Help builders move from ideas to executable systems.
